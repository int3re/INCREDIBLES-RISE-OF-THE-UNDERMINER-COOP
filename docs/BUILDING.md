# Сборка из исходников

[Документация](README.md) · [Как это устроено](ARCHITECTURE.md) · [История версий](CHANGELOG.md)

**Русский** · [English](en/BUILDING.md)

## Что нужно

- **Windows** и **Visual Studio 2022 или новее** с инструментами C++ (MSVC, x86).
- **CMake 3.20** или новее (подойдёт тот, что идёт с Visual Studio).
- **Python 3** — только для инструментов (манифест релиза, лаборатория).

Всё собирается под **Win32**: `incrotu.exe` — 32-битный процесс, и всё, что в него попадает, тоже
32-битное. Если настроить CMake на другую платформу, он остановится с ошибкой.

## Что берётся со стороны

| Что | Где сборка это ищет | Если этого нет |
|---|---|---|
| **ENet** (UDP) | `../tmnt2003-netplay/third_party/enet` — дерево [TMNT-2003-COOP](https://github.com/int3re/TMNT-2003-COOP), клонированное с `--recursive` рядом с этим. Другое место: `-DTMNT1_DIR=<путь>` | сборка не начинается |
| **Ultimate ASI Loader**, 32-битный | `../tmnt2003-netplay/third_party/ultimate-asi-loader/bin/Win32/Release/dinput8.dll` (его собирает там `tools/build_asi_loader.ps1`). Любая 32-битная сборка [загрузчика](https://github.com/ThirteenAG/Ultimate-ASI-Loader): `-DUAL_DLL=<файл>` | в результате нет `winmm.dll`, и лаунчер не собирается |
| **Steamworks SDK** | `../steamworks_sdk_165/sdk`. Другое место: `-DSTEAMWORKS_SDK_DIR=<путь к sdk>` | мод собирается только для игр по адресу |

MinHook лежит в репозитории (`third_party/minhook`). Steamworks SDK принадлежит Valve и в репозиторий не
входит никогда.

## Сборка

```
git clone https://github.com/int3re/INCREDIBLES-RISE-OF-THE-UNDERMINER-COOP
git clone --recursive https://github.com/int3re/TMNT-2003-COOP tmnt2003-netplay
cd INCREDIBLES-RISE-OF-THE-UNDERMINER-COOP
cmake -S . -B build -A Win32
cmake --build build --config Release
```

Результат — в `build/dist/Release`:

| Файл | Что это |
|---|---|
| `in2net-launcher.exe` | лаунчер с модом внутри: тот один файл, который идёт в релиз |
| `in2net.asi`, `in2net.ini`, `in2net-README.md` | мод, его настройки, его короткое описание |
| `winmm.dll` | Ultimate ASI Loader |
| `steam_api.dll` | библиотека Steam, если SDK нашёлся |

Только лаунчер: `cmake --build build --config Release --target in2net_launcher`. После смены версии (см.
ниже) запустите конфигурацию заново, чтобы пакет лаунчера о ней узнал.

Библиотека времени выполнения C подключается статически: распространяемый пакет Visual C++ игроку не
нужен.

## Дерево исходников

| Папка | Что в ней |
|---|---|
| `src/mod` | мод, `in2net.asi`: см. [Как это устроено](ARCHITECTURE.md) |
| `src/common` | общее для частей мода: журнал, сетевые транспорты (ENet, Steam, лабораторная замена Steam), протокол, SHA-256 |
| `src/launcher` | `in2net-launcher.exe`; его шрифты и значок — в `assets` |
| `dist` | то, что уходит игроку как есть: `in2net.ini`, короткое описание, `release.json` |
| `docs` | эта документация и картинки к ней |
| `tools` | манифест релиза, значок и шрифты лаунчера, шейдер картинки, лаборатория |
| `third_party/minhook` | MinHook |

## Версии

| Что | Где |
|---|---|
| версия мода | `src/common/version.h`, `IN2NET_VERSION` |
| сетевой протокол | `src/common/protocol.h`, `kVersion` — меняется всякий раз, когда две версии не сыграли бы одну и ту же игру |
| версия лаунчера | `src/launcher/launcher.h`, `kLauncherVersion` — меняется, когда меняется сам лаунчер |
| что релиз говорит о себе | `dist/release.json`: версия, протокол, дата, заголовок (не больше 40 знаков), от одной до четырёх заметок (каждая не больше 110 знаков), протоколы прежних версий |

## Релиз

Релиз — это два файла под тегом `v<версия>`: `in2net-launcher.exe` и `in2net-latest.json`.

1. Заполните `dist/release.json` и версии **до** сборки; запустите конфигурацию и соберите.
2. `python tools/release_manifest.py build/dist/Release/in2net-launcher.exe build/dist/Release/in2net-latest.json`
   — манифест: то, что записано в `release.json`, плюс размер и SHA-256 файла лаунчера. Лаунчер, собранный
   не из этих исходников, скрипт не принимает.
3. Опубликуйте оба файла как файлы релиза. Лаунчер запрашивает
   `<репозиторий>/releases/latest/download/in2net-latest.json`, а файл лаунчера берёт из
   `<репозиторий>/releases/download/v<версия>/`.

Адрес репозитория записан в `src/launcher/launcher.h` (`kRepoUrl`): форк, которому нужны свои обновления,
меняет его там.

## Лаборатория

`tools/lab` запускает копии игры с модом, ни разу их не показывая: окно стоит за пределами экрана и никогда
не берёт фокус, звук выключен, прогон заканчивается сам. Нужны ваши собственные копии игры в `../test-in2` и
`../test-in2b` (игра в репозиторий не входит) и Python с Pillow.

| Скрипт | Что он делает |
|---|---|
| `run_one.py <секунды> "<сценарий>" [строки debug]` | одна копия; нажатия по кадрам, снимки выбранных кадров |
| `run_twice.py` | один и тот же прогон дважды: одинаковы ли два журнала? |
| `run_net2.py <секунды> "<сценарий>"` | две копии в одной сетевой игре по адресу; журналы двух игр сравниваются кадр за кадром |
| `run_page.py <секунды> "<сценарий>"` | две копии встречаются на странице СЕТЕВАЯ ИГРА (через замену Steam или по адресу) и начинают с неё сетевую игру |
| `soak.py <секунды> <уровень> …` | пара в сетевой игре со случайной игрой, уровень за уровнем |

Сценарий — это строки вида `<кадр>[-<кадр>] [p2.]<управление>`: `420 start`, `600 down`, `700 a`,
`3000-3030 p1.mouse.left`. Переключатели лаборатории — это раздел `[debug]` в `in2net.ini`; каждый описан в
`src/mod/config.h`: сеть с потерями, зависшая игра, замедленная видеокарта (`slow`), привязки, которые
сообщаются игре без записи в реестр (`bind`), и другое.

Чего лаборатория проверить не может — так это настоящее окно игры перед игроком: клавиатуру, настоящую
мышь, Alt+Tab. Это проверяется игрой.

## Лаунчер без окна

| Команда | Что она делает |
|---|---|
| `in2net-launcher.exe --shot <экран> <файл.png>` | экран лаунчера в виде картинки: `ready`, `update`, `downloading`, `install`, `nogame`, `offline`, `settings`, `graphics`, `sound`, `controls`, `net` |
| `in2net-launcher.exe --drive "<шаги>" --pick <папка игры> --settings <ini> --cache <папка> --out <журнал> --keys <подраздел реестра>` | лаунчер под управлением сценария, окно не показывается: `until:<экран>:<мс>`, `click:<имя>`, `mouse:x,y`, `keydown:<vk>:<scan>:<ext>`, `state`, `shot:<png>`, `quit`. С `--keys` привязки и уровни громкости игры читаются и пишутся в другом разделе реестра, а не в разделе самой игры |
| `in2net-launcher.exe --check --out <журнал>` | спрашивает у GitHub самый новый релиз и записывает, что пришло |

## Чего нет в репозитории

- Файлов игры и Steamworks SDK.
- Заметок и инструментов разбора исполняемого файла игры. Адреса и структуры, которыми пользуется мод, есть
  в исходниках, в `src/mod/game.h`, — у каждой пояснение, что это.
