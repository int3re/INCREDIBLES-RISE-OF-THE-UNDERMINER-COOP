# in2net — documentation

**English** · [Русский](../README.md)

in2net is a network co-op mod for the PC game *The Incredibles: Rise of the Underminer* (2005), made for
its Russian release, «Суперсемейка: Подземная битва». The short story is on the
[front page](../../README.en.md); these pages are the long one.

| Page | What it is about |
|---|---|
| [What the mod adds and changes](TOUR.md) | a tour in pictures: the game's menus, a network game, the launcher |
| [Install](INSTALL.md) | what you need, installing, updating, removing; what is put where |
| [The launcher](LAUNCHER.md) | every screen and tab, updates, a proxy for GitHub, the command line |
| [Network play](NETPLAY.md) | meeting over Steam or by address, the rules of a network game, versions that play together |
| [Controls](CONTROLS.md) | the keys of both players, the mouse's buttons, how to change them |
| [Settings](SETTINGS.md) | the launcher's rows, the whole of `in2net.ini`, the game's own settings |
| [If something is wrong](TROUBLESHOOTING.md) | frequent questions; what to send with a report |
| [History of versions](CHANGELOG.md) | what changed from version to version |
| [Building](BUILDING.md) | building the mod and the launcher from source, releases, the test lab |
| [How it works](ARCHITECTURE.md) | lockstep, the game's clock, hooks, the native menus, the modules |

The mod and the launcher speak Russian. Names of buttons and menu items are given as they are on the
screen, with a translation in brackets where it helps.
